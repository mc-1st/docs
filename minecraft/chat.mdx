Această pagină prezintă regulile de comunicare pe serverul **MC-1ST** (mc-1st.ro). Toate regulile de mai jos se aplică în chatul public, chatul donatorilor, mesajele private, `/helpop`, `/eac`, denumiri de iteme, sign-uri, ganguri și orice altă formă de comunicare de pe server. Respectarea acestor reguli asigură un mediu plăcut și accesibil pentru toți jucătorii.

---

## Limbă și Comunicare

### Limbi Străine

<Warning>
  În chat este permisă utilizarea **limbilor română și engleză**. Folosirea altor limbi este interzisă pentru a menține o comunicare clară și accesibilă pentru toți membrii. Încălcarea acestei reguli prin utilizare repetată de fraze sau propoziții în alte limbi va duce la aplicarea unei sancțiuni.
</Warning>

**Sancțiune:** `Mute 30 minute`

---

## Insulte și Toxicitate

### Jigniri și Insulte

<Warning>
  Este interzis să jigniți, înjurați, amenințați sau să folosiți un limbaj vulgar pe chatul public. Jignirile prescurtate, cenzurate sau scrise în altă limbă sunt de asemenea sancționabile — exemplu: `plm`, `fmm`, etc.

  - Dacă regula este încălcată pe **chatul public sau chatul de donatori**: sancțiunea este **mute**.
  - Dacă regula este încălcată în **alte locuri** (nume de iteme, sign-uri, nume de gang, mesaje private `/msg`, helpop etc.): sancțiunea este **warn**.
</Warning>

**Sancțiune:** `Mute 2 ore` / `Warn`

---

### Toxicitate

<Warning>
  Nu tolerăm toxicitatea și glumele de prost gust adresate altor jucători. Toxicitatea include orice formă de insultă, ironie, sarcasm sau expresie jignitoare menită să denigreze sau să afecteze negativ experiența altor jucători.

  - Pe **chatul public sau donatori**: sancțiunea este **mute**.
  - În **alte locuri** (iteme, sign-uri, gang, `/msg`, helpop): sancțiunea este **warn**.
</Warning>

**Sancțiune:** `Mute 2 ore` / `Warn`

---

### Toxicitate Excesivă

<Warning>
  Dacă un jucător încalcă în mod repetat regula privind toxicitatea, comportamentul său va fi considerat **toxicitate excesivă**. Exemple:

  - Continui să faci comentarii toxice după ce ai fost sancționat deja de mai multe ori.
  - Încerci să eviți sancțiunile folosind ironie constantă, sarcasm sau expresii jignitoare indirecte.
  - Manifești o atitudine ostilă față de jucători, chiar și după diferite avertismente sau sancțiuni.
</Warning>

**Sancțiune:** În funcție de gravitate: `Suspendarea accesului la /donorchat` pe o perioadă nedeterminată (în cazul donatorilor), `Mute 12 ore`, `Ban 3–7 zile`

---

### Rasism

<Warning>
  Orice formă de rasism, fie directă sau indirectă, este strict interzisă. Manifestările de rasism în chat vor fi sancționate cu mute de 3 zile. În cazul în care rasismul se regăsește în denumiri de ganguri, iteme sau construcții, sancțiunea este ban 3 zile.
</Warning>

**Sancțiune:** `Mute 3 zile` / `Ban 3 zile`

---

### Jignire Staff / Server

<Warning>
  Jignirea, lipsa de respect, glumele de prost gust și ironia față de un membru al staff-ului sau față de server sunt strict interzise și se pedepsesc.
</Warning>

**Sancțiune:** `Mute 3 zile`

---

## Comportament în Chat

### Spam

<Warning>
  Spam-ul pe chat este complet interzis. Prin spam înțelegem scrierea aceluiași mesaj în mod consecutiv de mai multe ori. Aveți voie să repetați un mesaj de **maxim două ori**. Nu aveți voie să utilizați diferite formate sau variante ale aceluiași mesaj pentru a repeta aceeași idee.
</Warning>

**Sancțiune:** `Mute 1 oră`

---

### Caps Lock

<Warning>
  Este interzisă folosirea excesivă a **CAPS LOCK** în chat. Mesajele scrise predominant cu litere mari sunt considerate CAPS LOCK abuziv.
</Warning>

**Sancțiune:** `Mute 1 oră`

---

### Prelungire

<Warning>
  Este interzisă prelungirea excesivă a cuvintelor sau trimiterea de mesaje fără sens pe chat. Exemple: `saluuuuuut`, `haaaaaai`, `asidfallifasldfbas`.
</Warning>

**Sancțiune:** `Mute 1 oră`

---

## Alte Reguli

### Solicitare Favoruri de la Staff

<Warning>
  Este strict interzis să solicitați favoruri, iteme sau avantaje din partea membrilor staff-ului.
</Warning>

**Sancțiune:** `Warn`

---

### Acuzații de Hack pe Chat Public

<Warning>
  Nu este permis să acuzați un jucător de hack pe chatul public. Filmați și raportați pe Discord.
</Warning>

**Sancțiune:** `Warn`

---

### Reguli în /helpop, /eac și Mesaje Private cu Staff

<Warning>
  Toate regulile de la această categorie se aplică și în `/helpop`, `/eac` sau mesajele private cu membrii staff.
</Warning>

**Sancțiune:** `Warn`

---

### Dezvăluirea Datelor Personale

<Warning>
  Este interzis să dezvăluiți identitatea, locația, IP-ul, numărul de telefon, adresa etc. unei persoane.
</Warning>

**Sancțiune:** `Ban Permanent`

---

### Reclamă Indirectă

<Warning>
  Reclama indirectă este interzisă. Expresiile precum *„cine are server?"*, *„caut server"*, *„cine s-a jucat pe X server?"* vor fi sancționate.
</Warning>

**Sancțiune:** `Mute 7 zile`

---

### Promovarea Serverelor și Comunităților Externe

<Warning>
  Este interzisă promovarea sau menționarea comunităților, serverelor sau proiectelor care nu au legătură cu mc-1st.ro. Aceasta include servere Minecraft, alte jocuri (FiveM, Counter-Strike etc.) și servere Discord.
</Warning>

**Sancțiune:** `Ban Permanent`

---

### Promovarea Conturilor de Social Media

<Warning>
  Promovarea conturilor personale de social media (TikTok, Instagram, YouTube etc.) este interzisă atât în chatul public, cât și în mesajele trimise altor jucători.
</Warning>

**Sancțiune:** `Mute 3 zile` / `Warn`
